# TDD Demo — Bank Account

Демо-проект для презентации TDD. Реализуем банковский счёт через цикл Red → Green → Refactor.

## Запуск с нуля

### 1. Создать виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Установить зависимости

```bash
pip install -r reqirements.txt
```

### 3. Запустить тесты

```bash
pytest
```

### 4. Запустить тесты в watch-режиме (удобно для демо)

```bash
pip install pytest-watch
ptw
```
