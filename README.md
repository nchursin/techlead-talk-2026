# TDD Presentation

Презентация разделена на два основных файла:

- `main.typ` — контент и порядок слайдов
- `theme.typ` — тема, палитра, глобальные настройки и общие slide-хелперы

## Шрифты

Вёрстка проверена с системными шрифтами `Arial` и `Helvetica Neue`.

Если на твоей машине их нет или Typst подставил другой fallback, переносы могут поехать. В таком случае правь строку `#set text(font: ...)` в `theme.typ` и снова запускай `typst compile`.

## Быстрый просмотр

Собрать PDF один раз:

```bash
typst compile main.typ presentation.pdf
open presentation.pdf
```

## Режим с автопересборкой

Если хочешь править и сразу смотреть результат:

```bash
typst watch main.typ presentation.pdf
```

После этого Typst будет пересобирать PDF при каждом изменении `main.typ` и импортируемых файлов, включая `theme.typ`.

Открыть результат отдельно:

```bash
open presentation.pdf
```

## Что внутри

- `main.typ` — контент, порядок слайдов и точечная вёрстка отдельных слайдов
- `theme.typ` — палитра, глобальные `set`-настройки и общие slide-хелперы
- `План на доклад.md` — исходный план доклада
- `TDD — исследования.md` — заметки с исследованиями, на которые опирается слайд про скорость и качество
- `Мифы TDD.pptx.pdf` — старая презентация, из неё взят контент для слайда "О спикере"
